# Breast-Cancer-Detection
Breast Cancer Detection is a machine learning project that analyzes medical data to predict whether a breast tumor is benign or malignant. Using Python and Scikit-learn, the project applies data preprocessing, model training, and evaluation techniques to support early detection research and improve awareness of breast cancer.

**Common Symptoms of Breast Cancer**

Breast lump: A new lump or thickening in the breast.
Change in breast size or shape: One breast may look different from usual.
Breast pain: Persistent pain in the breast or nipple.
Nipple changes: The nipple turns inward or changes appearance.
Nipple discharge: Unusual fluid or blood coming from the nipple.
Skin changes: Redness, dimpling, or skin resembling an orange peel.
Swelling: Swelling in part or all of the breast.
Armpit lump: Swollen lymph nodes or a lump under the arm.
